# Grow Project Group

WordPress brochure theme: `wp-content/themes/grow-project-group/`.

Upload the theme ZIP using WordPress Appearance > Themes > Upload Theme, or copy the theme folder to an existing WordPress installation. No custom backend or integrations are included.

Project pages default to the designed PHP templates. Non-empty WordPress Page editor content replaces that page's template. Featured Images can override the project hero image. Concept imagery and consultant credits require approval before publication.
